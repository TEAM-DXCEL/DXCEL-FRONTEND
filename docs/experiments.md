# 실험 목록과 도메인 타입

현재 `/experiments`는 실제 연구 기록과 분리된 평가가 끝난 가상 실험 128개와 실행 전 설계 1개를 사용한다. 일부 실험은 평가 이후 재실행 상태를 함께 표시한다. 화면에 샘플 데이터임을 명시한다. DB·인증·수집 API는 연결하지 않았으며 실제 지표 값도 넣지 않는다.

## 타입과 DB 설계의 관계

`src/features/experiments/types.ts`는 백엔드 `docs/database-design.md`의 논리 설계에 맞춘 프론트 도메인 타입이다. DB에서 생성한 타입이나 확정된 API 응답 규약은 아니다. migration 구현 후 생성되는 DB 타입과 조회 adapter를 통해 연결한다.

| 타입 | 역할 |
| --- | --- |
| `Experiment` | 프로젝트 안의 고정 실험 번호, 담당자, 이전 실험, 현재 설계·대표 결과 참조 |
| `ExperimentRevision` | 가설·변경 내용·변경 이유·평가 계획의 버전 |
| `RunGroup` | 같은 비교 조건의 반복 묶음과 확정 상태 |
| `Run` | 개별 실행, 반복·재시도 번호, 이전 평가 참조와 상태 |
| `RunMetric` | 지표 정의 참조와 측정·결측·오류의 구분 |
| `ExperimentListItem` | 현재 설계와 최신 실행을 조합한 목록용 조회 모델 |

실행 성공은 실험의 개선이나 최종 확정을 의미하지 않는다. 최신 실행 상태와 대표 결과를 분리한다. 결과 정정·재평가는 이전 실행을 덮어쓰지 않고 새 실행으로 연결한다. 결측·오류 값을 0으로 표시하지 않는다.

상태 이름과 필드 이름은 이번 화면 구현의 초안이다. 프로젝트 간 참조·유한 수치·확정 후 불변성 등의 강제는 향후 DB·API에서 수행해야 하며 TypeScript 타입이 이를 보장하지 않는다. 샘플 ID는 가독성을 위한 문자열이며 실제 저장 식별자는 기존 설계의 UUID를 따른다.

## 화면 동작

- 번호·제목·담당자·변경 내용·변경 이유 검색: 검색 버튼 또는 Enter로 적용
- 최신 실행 상태: 실행 전·대기·실행 중·성공·실패·취소
- 최근 업데이트순 또는 실험 번호 오름차순·내림차순 정렬
- 최초 24개 표시 후 목록 하단에서 24개씩 이어지는 무한 스크롤, 변경 이유·가설·평가 계획 펼치기
- 로딩, 빈 목록, 검색 결과 없음, 조회 오류와 다시 시도 표시
- `q`, `status`, `sort` URL 파라미터로 조건 유지; 브라우저 뒤로·앞으로 이동 지원

잘못된 상태·정렬은 기본값으로 처리한다. 필터·검색·정렬이 바뀌면 표시 범위와 목록 스크롤을 초기화한다. 이전 page 파라미터는 사용하지 않는다. 날짜는 KST로 표시한다.

조회는 `repository.ts`의 `listExperiments(query, signal)`로 분리했다. 현재 샘플 전체를 메모리에서 검색·정렬하고 화면에서 24개씩 점진적으로 표시한다. 이는 실제 DB의 pagination 구현이 아니다. DB 연결 시 인증된 프로젝트 범위 조회와 cursor pagination을 구현하고 무한 스크롤의 추가 조회도 해당 cursor 응답 계약에 맞춘다. 실제 비공개 데이터를 정적 빌드에 포함하면 안 된다.

실제 DB의 실험 생성·편집, 상세 경로와 Baseline 선정은 포함하지 않는다. 비교 화면의 샘플 선택은 아래 시안 범위에 포함한다. 실제 지표 표시는 지표 정의와 확정 실행 묶음 계약을 구현한 뒤 연결한다.

## 비교 대시보드 시안

`/compare`는 세 축 레이더/평행좌표 비교, 부모 실험과의 조건 차이, 실험자×개선 목적 분류, 계보 기반 분포·추이, 무한 스크롤 아카이브를 제공한다. `src/lib/demo-research.ts`의 평가가 끝난 샘플 128개와 가상 연구자 4명을 목록과 공유한다. EXP-100은 EXP-80을 부모로 참조하며, 목적은 Privacy 개선이고 노이즈 설정 한 가지를 변경한 예시다.

비교 목록에서 서로 다른 계보의 실험을 함께 선택할 수 있다. 선택 개수 제한은 없으며 필터를 변경해도 선택 목록이 유지된다. 비교 표, 레이더와 평행좌표는 Baseline과 직접 선택한 실험을 표시한다. Overview는 세 지표가 모두 Baseline보다 좋은 실험을 최대 5개 보여준다. 전체 샘플에서 지표별 순위를 구하고, 세 순위 중 가장 낮은 순위가 더 높은 실험을 우선한다. 동률이면 평균 순위, 실험 번호 순으로 정렬한다. 평가 방향은 축이 아닌 지표별로 정의한다. 시안은 MIA AUC(전체 출력·최대 AUC), XGB PR-AUC, 3-way WD에 가상 원점수를 표시한다. 목표형 지표의 개선량은 Baseline 대비 목표 오차 감소량이며, 값이 없는 지표는 미측정으로 표시한다. 샘플의 0–1 범위를 실제 WD 등 모든 지표에 적용하지 않는다. 면적을 종합 성능이나 순위로 해석하지 않는다. 분류 집계는 개선을 달성한 개수가 아닌 해당 목적으로 설계된 실험 수다. 조건 표에서는 생성·학습 설정과 공통 평가 조건을 구분한다.

실제 DB·API는 연결하지 않았다. 무한 스크롤은 현재 메모리에 있는 샘플의 점진 표시이며 네트워크 cursor pagination 구현이 아니다. 끝의 더 불러오기 버튼은 키보드·IntersectionObserver 미지원 환경용 보조 동작이다.
